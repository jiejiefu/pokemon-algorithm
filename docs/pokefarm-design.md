# PokéFarm（寶可夢農場）設計筆記

> 狀態：v0.1 原型（`pokefarm.html`）。本文件是腦力激盪的整理，也是之後擴充的地圖。
> 帶 **【v0.1】** 的項目已經做進原型；其餘是下一步的候選，不是承諾。

## 1. 一句話

經營一座樹果農場：把有限的時間（一天 120 秒）和有限的人手（寶可夢）分給五花八門的農務，
同一天可以交給演算法，也可以自己指揮，事後比較誰賺得多。

這個專案的主題是「用寶可夢看懂演算法」，農場補上的是**排程（scheduling）**：
貪婪、最早到期優先、最近優先、先進先出，不是講義，而是你每天都在做的選擇。

## 2. 設計支柱

1. **每隻寶可夢都有用，但用處不同。** 技能不是裝飾，要能改變你怎麼分工。
2. **時間和資源永遠不夠。** 一天 120 秒、水槽有限、柴火有限；缺什麼，就是這天的謎題。
3. **看得見的演算法。** 每個決策都能被展示：誰被派去哪、為什麼。
4. **可以放手。** 不想動手時切到自動排程，看它做；想動手時，隨時接管。
5. **跟圖鑑相連。** 每天只有來農場拜訪的寶可夢可以雇用；雇用訪客會把牠收進圖鑑。

## 3. 2D、2.5D、還是 3D？【已決定】

結論：**俯視 2D 格子地圖（Gen III 的視角），工人用 DOM 疊上去的 GIF。**

| 方案 | 優點 | 卡在哪 |
| :--- | :--- | :--- |
| Three.js 全 3D | 有景深、可旋轉 | Showdown 的動畫是 **GIF**，WebGL 紋理拿到的只有第一格，要自己逐格解碼成圖集；3D 模型庫（`assets/glbs`）只有部分寶可夢；每隻都要接骨架動畫。工作量是整個專案的 3 倍，而且農務的核心是「誰去哪」，不是鏡頭 |
| 2.5D（CSS 旋轉成等角） | 立體感 | 像素圖旋轉後會糊，GIF 必須反向旋轉才站得直，點選座標要做矩陣換算，格子越多越容易出錯 |
| **俯視 2D（採用）** | 像素風最乾淨；GIF 直接當 `<img>`，瀏覽器本身負責動畫；移動只靠 `transform`（GPU）；手機觸控好點 | 沒有景深。用前景樹、陰影、Y 排序補一點層次 |

工人面向用 Showdown 的兩張圖：**往下走用正面 GIF，往上走用背面 GIF，左右用 `scaleX` 翻轉**。
一個動作都不用另外畫。

## 4. 一天的循環【v0.1】

```
晨間：看訂單、挑種子、指派工人
白天（120 秒，可 1×/2×/4×）：農務自己跑
黃昏：自動結算、賣出、顯示「如果交給演算法」的對照
夜間：作物長大一些（夜間成長），下一天
```

### 農田狀態機

```
荒地 ──清理(割草/放火)──▶ 休耕 ──翻土──▶ 已翻 ──播種──▶ 生長(1→4 階段) ──▶ 成熟
  ▲                                                                           │
  └────────────────────────── 殘株 ◀───────── 採收 ◀───────────────────────────┘
```

- 生長每階段要澆一次水。**每多澆一階段，收成多一點**（Gen III 的規則：全程沒澆就只有最少收成）。
- 野草會隨機長在已翻田和生長中的田，長了草，成長速度減半，要除草。
- 殘株可以割掉（慢），也可以**放火燒**（快，而且留下灰燼 = 這輪多收 1 顆），但火會
  延燒到相鄰且**乾燥**的生長中樹果。水系寶可夢先澆濕鄰居，是一個真的有用的配合。

## 6. 技能系統

每隻寶可夢有三層：

1. **屬性親和**（所有 1,025 隻都有）：屬性決定擅長哪幾種工作，見下表。雙屬性取兩邊的最高值，
   另一邊給一半，避免雙屬性永遠贏。
2. **體格**（從公開資料推算）：種族值總和 → 整體工作效率；身高 → 力氣與速度的取捨
   （大隻的搬得多、走得慢）。
3. **專長**（少數有名的寶可夢，手工指定）：用招式或特性做的主動／被動效果。

### 個體狀態

- **體力**：每件工作耗一點，歸零會累倒休息；吃料理（或樹果）回復。這讓「多雇人」不是無腦解。
- **心情**：被派去不擅長的事會降低；低心情跑得慢。路線圖。

## 7. 排程策略：這個專案的演算法

原型內建 4 種自動策略，每個都用「同一組種子」跑一遍：

| 策略 | 規則 | 優點 | 缺點 |
| :--- | :--- | :--- | :--- |
| 先進先出 | 最早出現的工作先做 | 公平，不餓死 | 完全不看價值 |
| 最近優先 | 離工人最近的先做 | 省走路 | 可能一直不做遠處的收成 |
| 貪婪（價值/時間） | `任務價值 ÷（走路＋工作時間）` 最大先做 | 通常收益最高 | 容易忽略快到期的訂單 |
| 最早到期（EDF） | 離截止時間最近的先做 | 不漏訂單 | 有時為了趕一單放著大收益 |

**結算畫面的對照**（原型的招牌功能）：一天結束後，用當天的起始狀態和種子，
讓四種策略各跑一次，列出誰賺多少。你可以看到「自己指揮 vs 演算法」。
引擎是純函式、固定步長、可序列化，所以這是便宜的。

價值模型（`taskValue()`）是啟發式，不是真值：播種／澆水的價值來自它推進的收成，
搬運的價值是貨物賣價的一部分，料理的價值是成品和原料的差。

延伸（路線圖）：多工人 ≈ 多處理器排程；工人專長 ≈ 異質處理器；
訂單 ≈ 有截止時間的即時排程。可以做「關卡」，限制只能用某一種策略。

## 8. 經濟與進度

- 金幣用途：種子、新田（4 塊一組）、雇用工人（把拜訪的寶可夢留下來）、水槽升級。
- **訂單**：見 8.0（v0.2 已實作）。
- **市場**：【v0.1】每天有一種「今日熱銷味道」，該味道的料理 +50%，逼你換種的樹果。
- **夜間成長**：每過一晚，所有作物再長一點，所以不是每天都得從零開始。
- **金幣回收（v0.1.1 平衡）**：模擬顯示第 6 天後金幣會滾到 2 萬、沒有東西可買，所以加了
  - 每日工資：每位工人 工資 ÷ 14，日終扣，最低扣到 0；
  - 賣價飽和：同一種樹果前 10 顆全價、之後每顆 ×0.95；同一天料理前 4 道全價、之後 ×0.93
    （單一品種日收入約 800，輪種約 1,500–2,000，逼你換種、做料理）；
  - 永久升級：工具（12 級，工作快 8%/級）、廚房（8 級，料理倍率 +0.15/級）、推車（3 級，多搬 1），價格 = 基價 × 倍率^等級；
  - 雇用愈多愈貴：第 4 位起每多一人工資 +15%。
- 存檔：`localStorage`（`pokemon-algorithm:farm:v1`），壞資料直接重新開始，不丟例外。

### 6.1 特性專長（v0.3）

專長不再只靠手寫的幾隻：`species_abilities.json` 有 1,025 隻的真實特性，`ABILITY_PERKS`（約 110 種特性 → 農場效果）
把它們變成專長。每個工人取「第一個一般特性＋第一個隱藏特性」，有對應的就生效（超過 800 隻至少有一個）。

| 類別 | 例子 | 效果 |
| :--- | :--- | :--- |
| 天氣加速 | 葉綠素／悠游自如／撥沙 | 晴／雨／強風時走路與工作都快 30–40% |
| 體力 | 毅力、不眠、結實 | 體力池 +15–40% |
| 驅蟲 | 威嚇、惡臭、銳利目光 | 驅趕害蟲快 20–60% |
| 撿錢 | 拾取、採蜜 | 做完工作有機率撿到金幣 |
| 豐收 | 收獲、熟成、天恩 | 採收後再長一輪／多收 1 顆 |
| 放火 | 引火、火焰之軀、熔岩鎧甲 | 放火不延燒隔壁的田 |
| 專業 | 靜電（提水）、技術高手（播種）、堅硬腦袋（砍材）、貪吃鬼（料理） | 對應工作快 15–40% |
| 搬運 | 頰囊、黏著、吸盤、磁力 | 一次多搬 1／搬運快 30% |
| 全能 | 大力士、瑜伽之力 | 所有工作快 30% |

所有加成疊加後工作效率上限 3.5 倍。「強風」是沙暴的替身，所以沙隱、撥沙、沙之力都吃強風天。

### 6.2 搖樹與挖渠道（v0.3）

- **搖樹**：每棵樹每天可搖一次，掉 1–2 顆野生樹果（多半便宜的，12% 是好的）到樹下的堆放區等人搬；
  野生樹果讓你不必種滿品種就能湊齊料理與訂單。格鬥系最擅長（1.6 倍），其次飛行、草。
- **挖渠道**：田的左右各 4 格路面可以挖成渠道，挖好是永久的，旁邊那一格田每個階段開始自動吸水（跟下雨一樣）；
  乾旱時渠道乾涸。地面、岩石、水系挖得快。

### 8.0 訂單與信譽（v0.2）

- 每天早上有 2–4 張訂單（信譽 0 時 2 張，信譽 3 時 3 張，信譽 8 時 4 張），種類三種：**樹果**（指定品種 N 顆）、
  **料理**（含指定味道的料理 N 道）、**木材**（N 份）。通知期 1–3 天（第 1、2 天至少 2 天），通知越短獎勵越高（×1.9 / 1.7 / 1.55）。
- **日終自動交貨**：只要庫存備齊就交（不必等到截止日）；到了截止日還沒備齊就作廢。交貨 +1 信譽、作廢 −1 信譽（不低於 0），
  獎勵 ×(1 + 2% × 信譽，最多 15 點)。
- **庫存保護**：還沒到期的單所需的樹果和料理，日終賣出時會幫你留下；欠訂單的樹果不會被工人拿去做料理
  （瀏覽器測試抓到過：工人把客人要的橙橙果做成料理，已備齊的單反而逾期）。
- **對排程的影響**：greedy 的估值會替「有人在等」的東西加分（有缺口的樹果採收 +3、缺木材時砍材 8、符合訂單味道的料理 +25），
  所以訂單是排程之外的第二條決策線：種什麼、做哪種料理、要不要先砍柴。
- 介面：訂單分頁（卡片：品項、截止日、進度條、獎勵；今天截止紅邊、已備齊綠邊）、HUD 的訂單／信譽／今日到期、
  日終的訂單結果清單、晨間簡報（天氣＋訂單＋熱銷味道）、「怎麼玩」導覽（第一次自動開啟，可由「?」重開）。

### 8.1 天氣與蟲害（v0.1.1）

- 每天一種天氣，日終用世界自己的 RNG 抽下一天，所以 snapshot 已經帶著明天的天空，四種策略重播看到的是同一天。
  第 1 天一定是晴天。晴 50%、雨 22%、乾旱 14%、強風 14%。
  - 雨：作物自己吸水，不用澆；雜草長 1.5 倍快。
  - 乾旱：一早水槽只剩一半，提水一次也只補一半。
  - 強風：熟透的樹果掉得更快（腐爛 ×0.7 時間），放火延燒機率 ×2。
- **預報**：隊上有超能力系工人才看得到明天的天氣，否則顯示「？」。
- **蟲害**：第 3 天起，每天 40% 有一次、其中再 12% 有第二次來訪，時間隨機。害蟲停在一格成長中／成熟的田，
  22 秒內沒人「驅趕」就啃一口（成長中：這一階段進度歸零；成熟：少 2 顆）。惡／幽靈系驅趕最快，蟲系最慢（自己人）。

### 8.2 四季、天災與一年一局（v0.4）

**一局 = 一年 = 28 天**（四季各 7 天）。第一局隨機抽起始季節，之後可自選；一年結束出評級，可「再來一年」或進無盡模式。

| 季 | 屬性群組（工作 +15%） | 關鍵屬性（借人） | 規則 | 天氣 |
|---|---|---|---|---|
| 春 | 草 蟲 妖精 一般 飛行 | 草（走路草） | 種子 −25%、長得快 10%、雜草 +40% | 晴 雨 風 打雷 洪水 |
| 夏 | 火 水 電 格鬥 | 火（六尾） | 熟果更快爛、夜裡水槽不補水 | 乾旱 打雷 颱風 … |
| 秋 | 岩石 地面 毒 惡 幽靈 | 岩石（小拳石） | 樹果 +20%、訂單 +15% | 風 颱風 霜 … |
| 冬 | 冰 鋼 超能力 龍 | 冰（小山豬） | 長得慢 20%、料理 +20%、日終要燒木材（沒柴隔天體力 −15%） | 雪 寒流 … |

- **軟限制**：不是「只能選該群組」（那會讓雇用池變 4 分之 1），而是「群組內快 15%」加「關鍵屬性沒有就借一隻（本季免工資、季末歸還）」。嚴格版留給挑戰模式。
- **災害**（天氣日早上決定時刻，存在 world 裡所以黃昏重播看到同一片天）：打雷 2–3 道、洪水、颱風登陸（成熟作物和地上的堆減半）、寒流（幼苗 50% 凍死）；蝗災（夏秋）一早一大群蟲。落雷前 4 秒棋盤上閃黃框。
- **反制**：電系／避雷針、儲水、乾燥皮膚類特性引雷（兩隻可引走約 90%）；渠道在田旁就不淹，水系／排水特性救回 50%；火系／暖身特性讓幼苗只凍死 15%。
- **部分資訊**：超能力系、預知夢、危險預知的工人能在早上看到整天災害的時刻和明天的天氣，其他人只有發生前幾秒的預警。
- **星星與評級**：每季依「營收」（不是淨資產，投資不被懲罰）拿 0–3 星，門檻 = 3500／6500／10000 × 當週倍率 [1, 1.6, 2, 2.2]；全年 12 星＋總營收決定 S／A／B／C（用天真機器人量過：偷懶的 FIFO 組合約 C 級、一直雇人升級的貪婪組合約 A 級，S 要靠玩家自己避雷、防洪、接訂單）。個人最佳存在 localStorage。

### 8.3 音樂與音效（v0.4）

45 首紅藍配樂（原始 `.m4a`，51 MB）＋ 328 個初代招式音效（6 MB），詳見 `assets/audio/README.md`。`pokefarm-audio.js` 有兩層：**音樂導演**（`pickTrack(scene)` 是純函式：標題／早晨／白天依季節七首輪播／災害換戰鬥曲／最後一天最終對戰／黃昏＝勁敵登場／季末依星數／年終 進化→名人堂或片尾）與 **音效拼貼**（工作完成播對應招式，約一半機率換成工人本屬性的招式，招式的分段與 Direct 版隨機混入）。`check_pokefarm_audio.mjs` 證明全部檔案都可達。瀏覽器規則：第一次點擊才發聲、分頁隱藏就暫停、靜音／音量記在 localStorage、載入失敗全部靜默。**目前只接 Gen 1 的 328 個音效**；Gen 2–7 與素材說明保留在 `data-sources/audio-sources/`（gitignored）。未來擴充不能只丟檔案：`pokefarm-audio.js` 的 `JOB_MOVES`／`TYPE_MOVES`／`EVENT_MOVES` 要補對應，`check_pokefarm_audio.mjs` 的 328／45 計數與 70 MB 上限也要一起改。

### 8.4 這個遊戲「好玩」嗎？對照設計原則

| 原則 | 這裡怎麼做 |
|---|---|
| 清楚目標 | 一年 28 天、12 顆星、S 級 |
| 有意義的取捨 | 種什麼（季節價格）／雇誰（工資 vs 屬性）／留木材過冬／要不要挖渠道 |
| 部分資訊 | 只有預知型工人看得到災害時刻 |
| 快速回饋 | 每個工作有音效和彈字、落雷閃光、颱風震動 |
| 升高張力 | 四季災害越來越多、星星門檻逐週上升、最後一天換最終對戰曲 |
| 掌握感 | 手動指派打贏四種演算法；黃昏有量化比較 |
| 變化／重玩 | 起始季節、隨機天氣與災害、每天訪客、每次招募不同 |
| 風險／報酬 | 賭天氣早收還是等價高；雇人 vs 工資 |
| 敘事／身分 | 你的圖鑑收服的寶可夢就是你的員工 |
| Juice | 音樂隨天氣換、閃光、震動、星星逐顆亮 |
| 短局 | 一天 2 分鐘；一年約 1 小時（可存檔在早晨） |
| 分數／個人最佳 | S/A/B/C ＋ 最佳紀錄 ＋「還差幾顆星」 |
| 再來一局 | 結算直接「再來一年」，起始季節不同 |

### 8.5 挑戰模式與每日固定種子（v0.5）

- **挑戰模式（嚴格）**：第一週是適應週、大家都能上工；第二週起，每季只有該季屬性群組的工人能上工（借來的幫手永遠可以），其他人休眠但照領工資——所以不能一路堆人，要為四季各備一組班底（冬天的冰／鋼／超能力／龍最難）。門檻與評級是普通模式的 70%（`STRICT_SCALE`），個人最佳另存 `…:strict`。休眠的避雷針／排水／暖身／預知工人不算數（`crew()` 與預知都只算上工的）。機器人實測：偷懶約 C；會按季雇人的貪婪組合約 B；普通模式同一組合約 A。
- **每日固定種子**：種子與起始季節只由日期（台北時區）決定。早晨擲的東西（熱銷味道、明天天氣、蟲害、災害、訂單）改用 `hash(seed, day)` 的獨立亂數流（`atDawn`），玩家工人「運氣」消耗的亂數不會讓天空分岔，所以全世界今天玩的人看到同一年。沒有伺服器，所以沒有排行榜：結算給「複製成績」文字（`📅 … B 級 10/12★ …` ＋ 四季星星）、當天最佳與連續天數存在 localStorage，貼給朋友比。
- **沒做**：全球排行榜（要後端）、每週挑戰。

## 9. 跟網站其他部分連在一起

- **可雇用的工人 = 今日訪客**。圖鑑已收服的寶可夢不會另外列在招募清單；已經收服過的物種如果今天來訪，
  仍然會出現在訪客裡（雇用只會多一位工人，不會重複收服）。訪客有 4 隻，由「存檔種子＋遊戲內第幾天」決定
  （不是用現實日期，這樣每個存檔的農場各自不同、也能重玩）；雇用訪客會 `dex.catch(id, 'farm')` 收進圖鑑，
  這是首頁收集遊戲的第二條路。商店只在早上營業（一天進行中不能改，日終的演算法重播才公平）。
- **訪客池 = 455 隻「無前置進化的非寶寶、非傳說／幻之」**。寶寶（皮丘、皮寶寶、利歐路……）不該被叫來工作，
  所以先從進化圖移除，讓皮卡丘、皮皮、路卡利歐成為各自鏈的第一階；傳說／幻之的 Showdown 畫布太大
  （蓋歐卡 234×55、伊裴爾塔爾 201×188），留著會讓田裡的比例失控。清單以 ranges 存在
  `pokefarm-data.js`，`check_pokefarm_engine.mjs` 每次從 `evolution_levels.json` 重算並要求完全一致。
- 剛開始送三隻（小火龍／傑尼龜／妙蛙種子），所以空圖鑑也能開局。

- **GIF 連網載入**：`raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/showdown/{id}.gif`
  （背面在 `back/{id}.gif`）。不進 repo，不增加專案大小。

## 11. 其他玩法點子（腦力激盪，先留著）

- **天氣**：下雨自動澆水（水系工人這天可以休息去搬運）；烈日讓水蒸發快，土壤變乾。
- **季節／樹果種類**：不同樹果不同成長時間、味道、價格。長的賣得貴但占地久。
- **害蟲事件**：蟲屬性訪客啃樹果；惡屬性工人可以趕走；超能力可以預告。
- **夜間工作**：幽靈系有夜班，不扣體力；夜間有不同的訂單。
- **雜交樹果**：兩種相鄰成熟的樹果，下一輪機率長出新品種（味道混合）。
- **農展會**：用料理參加比賽（呼應 Pokéblock／Poffin 與華麗大賽），比味道平衡。
- **雜貨商**：每隔幾天出現，用特定樹果換稀有道具（肥料、噴霧器）。
- **工人關係**：誰跟誰搭檔效率更高（同蛋群、同進化系）。
- **挑戰關卡**：「只許用 EDF」「只有 2 隻工人」「禁止放火」，把排程演算法變成關卡規則。
- **成就／圖鑑連動**：雇用過 50 種屬性組合、單日 1000 金幣等等。
