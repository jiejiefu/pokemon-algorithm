# Python dependencies for scripts/

# There was no manifest in this repo before 2026-09-30; the interpreter in use
# lives at ../.venv (one level above the project root), which is why nothing
# here was discoverable from a clone. These are the third-party packages
# imported by tracked scripts, pinned to the versions that were actually
# verified against this data. Transitive dependencies are left to pip.
#
#   python -m pip install -r requirements.txt
#
#   The colour-palette generator needs only the first three:
#     python scripts/extract_color_palettes_mmcq.py

# --- cry audio (scripts/fetch_gen1_cries.py, analyze_cries.py) ----------------

# libsndfile bindings. The Gen-1 fetcher has to transcode the APU's 2-bit PCM
# itself (libsndfile has no raw reader for it), but it still needs to *write* a
# container, and the feature analyser needs a Vorbis/MP3 decoder — which
# libsndfile supplies via its bundled mpg123. Pinned to the pair verified
# against the 1,674 upstream cry files: mpg123 is load-bearing, not transitive,
# because without it soundfile reports MPEG layer III files as unsupported.
soundfile==0.14.0

# NOTE on OpenCC: two different distributions both install a top-level `opencc`
# package and they overwrite each other's files. `OpenCC` (the ctypes binding)
# and `opencc-python-reimplemented` (pure Python) are both present in the venv
# this was pinned from; the ctypes one is what actually imports, which is how
# it was identified — `opencc.__version__` reports 1.4.2, and the installed
# directory has `clib/` and `opencc.py` rather than the reimplemented layout.
# Only `OpenCC` is pinned above. Do not "fix" a missing opencc by installing
# opencc-python-reimplemented alongside it: that silently replaces the working
# package, and the swap is invisible until a name converts wrongly.
